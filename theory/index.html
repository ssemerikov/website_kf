§ 8. Квадратична функція, її графік і властивості

Вивчаємо одну з найважливіших функцій у шкільному курсі математики.

Означення: Квадратичною функцією називають функцію, яку можна задати формулою вигляду $$y = ax^2 + bx + c$$ де $x$ — незалежна змінна, $a, b, c$ — деякі числа, причому $a \neq 0$.

У підручнику (Школьний О. В.) наголошується: умова $a \neq 0$ є критичною, адже саме доданок $ax^2$ робить функцію квадратичною.

Парабола: графік квадратичної функції

Графіком квадратичної функції є крива, яку називають параболою. Розглянемо найпростішу параболу $y = x^2$.

  • Якщо $a > 0$, гілки параболи спрямовані вгору.
  • Якщо $a < 0$, гілки параболи спрямовані вниз.
  • Вісь $Oy$ є віссю симетрії для $y = ax^2$.

Алгоритм побудови та властивості

Для побудови графіка $y = ax^2 + bx + c$ використовують такий алгоритм:

  1. Визначити напрям гілок (за знаком $a$).
  2. Знайти координати вершини $x_0 = -\frac{b}{2a}$, $y_0 = f(x_0)$.
  3. Знайти нулі функції (розв'язавши рівняння $ax^2 + bx + c = 0$).
  4. Знайти точку перетину з віссю $Oy$ (це точка $(0; c)$).
Властивість Опис для $a > 0$
Область визначення $D(f) = (-\infty; +\infty)$
Область значень $E(f) = [y_0; +\infty)$
Зростання На проміжку $[x_0; +\infty)$

4. Перетворення графіків

Як з базової параболи $y = x^2$ отримати будь-яку іншу?

  • $y = x^2 + k$ — зсув вгору/вниз по осі $Oy$.
  • $y = (x - h)^2$ — зсув ліворуч/праворуч по осі $Ox$.
  • $y = ax^2$ — розтяг або стиск відносно осі $Ox$.

У підручнику (Школьний О. В.) ці перетворення розглядаються як основний інструмент для швидкої побудови складних функцій.

5. Цікаво знати

Парабола — це не просто лінія в зошиті. Вона всюди:

  • Архітектура: Форма арок мостів часто наближена до параболічної для кращого розподілу ваги.
  • Техніка: Параболічні антени збирають сигнали з космосу в одну точку — фокус.
  • Природа: Траєкторія м'яча, кинутого під кутом — це парабола.
